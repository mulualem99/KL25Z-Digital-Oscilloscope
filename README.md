# KL25Z Digital Oscilloscope

## Overview
This project implements a 1-channel digital oscilloscope using the FRDM-KL25Z microcontroller. The system performs analog signal acquisition, processes sampled data, and displays waveform output using an SPI-based TFT display. The project demonstrates embedded C programming, microcontroller peripheral integration, hardware/software system design, and real-time waveform visualization through an embedded systems approach.

## Features
- 1-channel digital oscilloscope implementation
- Analog signal acquisition using ADC
- SPI-based TFT display visualization
- Embedded C programming
- Real-time waveform display
- Hardware/software integration
- Microcontroller peripheral configuration
